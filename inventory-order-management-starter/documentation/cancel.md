## Отмена заказа

Запрос:

```bash
curl -i -X POST http://localhost:8080/orders/1/cancel
```

Замените `1` на ID существующего заказа.

Ответы:

- `204 No Content` — заказ отменён; тело ответа отсутствует.
- `204 No Content` — заказ уже был отменён; повторного возврата товаров нет.
- `400 Bad Request` — некорректный ID.
- `404 Not Found` — заказ не существует.
- `500 Internal Server Error` — внутренняя ошибка.

При отмене заказ и его позиции сохраняются в БД. Статус меняется
на `cancelled`, а количества из позиций возвращаются в остатки товаров.

Возврат остатков и изменение статуса выполняются в одной транзакции.
Строка заказа блокируется через `SELECT ... FOR UPDATE`, поэтому
конкурентные отмены одного заказа не возвращают товары повторно.
При ошибке до фиксации транзакции изменения откатываются.

Товары обновляются по возрастанию ID. Другие операции, изменяющие
несколько товаров, должны придерживаться такого же порядка блокировок.

Реализация предполагает, что создание заказа и его позиций атомарно,
а позиции созданного заказа впоследствии не изменяются.
